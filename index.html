## 1. 배열의 모양 읽기 (15분)

`shape`은 배열을 계산하기 전에 반드시 확인해야 하는 정보입니다.

- `(3,)` : 값 3개인 1차원 배열
- `(2, 3)` : 2행 3열인 2차원 배열
- `ndim` : 축의 개수
- `size` : 전체 원소 개수
실행 코드
one = np.array([10, 20, 30])
two = np.array([[10, 20, 30], [40, 50, 60]])
for name, arr in [('one', one), ('two', two)]:
    print(name, 'shape=', arr.shape, 'ndim=', arr.ndim, 'size=', arr.size)
실행 코드
# 확인 실습: 아래 배열의 shape을 실행 전에 종이에 적으세요.

b = np.array([[[1, 2, 3]], [[4, 5, 6]]])
print('a:', a.shape)
print('b:', b.shape)
## 2. 브로드캐스팅 규칙 (15분)

NumPy는 두 배열의 **뒤쪽 차원부터** 비교합니다. 각 차원이 다음 중 하나면 계산할 수 있습니다.

1. 두 크기가 같다.
2. 둘 중 하나의 크기가 1이다.
3. 한쪽에 해당 차원이 없다.

예: `(2, 3)`과 `(3,)`은 가능하지만 `(2, 3)`과 `(2,)`는 불가능합니다.
실행 코드
table = np.array([[10, 20, 30], [40, 50, 60]])
scalar = 10
column_rule = np.array([1, 2, 3])
print('원본 shape:', table.shape)
print('스칼라 +10\n', table + scalar)
print('각 열에 [1,2,3] 더하기\n', table + column_rule)
### 손으로 먼저 계산하기

  • CSV를 읽고 한 열을 Series로 추출한다.
  • 기술통계와 value_counts를 사용한다.

교사용 핵심 설명

데이터 읽기→열 선택→집계의 3단계로 말하게 한다.

수업 흐름 도입·예측 10분 → 개념 설명 20분 → 코드 따라하기 25분 → 개별 미션 25분 → 결과 설명·정리 10분
실행 코드
# 공통 준비: 라이브러리와 데이터 경로
from pathlib import Path
import numpy as np
import pandas as pd
DATA = Path('../data')
print('데이터 폴더:', DATA.resolve())
실행 코드
df=pd.read_csv(DATA/'survey.csv')
display(df)
s=df['만족도']; print(s.describe())
display(df['관심분야'].value_counts())
실행 코드
# 실습: 만족도가 4 이상인 응답자의 관심분야 빈도
high=df.loc[df['만족도']>=4,'관심분야']
display(high.value_counts())

### ① CSV 분석 질문 — 10분
열 이름만 보고 답할 수 있는 질문을 만든다. 오늘 질문은 “관심 분야별 만족도 차이가 있는가?”로 정한다.
### ② 파일 점검 — 15분
`read_csv` 후 `head`, `shape`, `columns`, `dtypes`, `info`를 확인한다. 한 행과 한 열이 의미하는 바를 말한다.
### ③ Series 추출 — 15분
대괄호 한 번과 두 번의 반환 자료형 차이를 확인한다. `unique`, `nunique`, `value_counts(normalize=True)`를 사용한다.
### ④ 조건과 집계 — 20분
만족도 4 이상 응답자를 고르고 관심분야 빈도를 계산한다. 분야별 평균 만족도도 구해 서로 다른 질문임을 설명한다.
### ⑤ 결과 저장·재확인 — 15분
결과를 `index=False`, `utf-8-sig`로 저장하고 다시 읽어 행 수와 열 이름을 검증한다.
### ⑥ 해석 — 15분
핵심 수치 2개, 결론 1문장, 표본이 작다는 한계 1개를 작성한다.

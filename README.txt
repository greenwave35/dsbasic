파이썬 데이터·그래프 16회차 수업자료

1. index.html을 더블클릭하면 전체 강의안을 볼 수 있습니다.
2. Jupyter/Colab에서 notebooks 폴더의 회차별 파일을 엽니다.
3. 로컬 실행 권장 설치: pip install numpy pandas matplotlib jupyter
4. 노트북은 notebooks 폴더 위치를 기준으로 ../data 파일을 읽습니다.
5. Colab 사용 시 data 파일도 함께 업로드하고 경로를 알맞게 바꾸세요.

기존 압축자료의 Series, DataFrame, 결측치 워크시트와 gildongs 데이터를 반영해 확장했습니다.
